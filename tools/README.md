# Rebuilding the profile graphics

Every image in the profile README is generated by `build.py`, so edit the text there
(credentials, toolkit, headers) rather than in the SVG files.

One-time setup, from this `tools/` folder:

```sh
pip install fonttools brotli
npm install @fontsource/space-grotesk @fontsource/ibm-plex-sans @fontsource/ibm-plex-mono
git clone --depth 1 https://github.com/tandpfun/skill-icons
```

Then rebuild everything into `../assets`:

```sh
python3 build.py
```

The script measures text with the real fonts and stops with an error if a line or chip
row would overflow, so shorten the text it names and run it again.

`node_modules/` and `skill-icons/` are only needed locally; they're in `.gitignore`.
